# Man pages (Ch 02, Sec 00)

**command:** `man [cmd]`
* gives the manual for given command in a pager
* `man man` is an interesting exercise to learn about sections

**command:** `help [built-in BASH cmd]`
* man for shell commands

**command:** `type [cmd]`
* gives the type of command
* ex: shell vs external bin

**command:** `compgen -b`
* gives all shell commands

**command:** `file [file]`
* tells you what type of file a file is such as ASCII text, types of executables etc.

**command:** `tr [sym1] [sym2]`
* (translate)
* turns `sym1` to `sym2` such as `;` to `\n`
